# Assignment 2 - CSS Styling

## File Organization
- `index.html`: Contains the core structure of the page with six box elements. 
- `styleA.css`: Displays the boxes vertically aligned in the center, with alternating background colors and specific borders.
- `styleB.css`: Displays the first five boxes horizontally with hover effects, and pins the last box to the bottom right corner of the window.

## Challenges Faced
- Managing the Flexbox layout to ensure the boxes stay perfectly spaced vertically in Style A without changing their dimensions when the browser resized.
- Keeping the last box fixed to the bottom right in Style B while ensuring the rest of the boxes didn't wrap to the next line using `white-space: nowrap;`.
